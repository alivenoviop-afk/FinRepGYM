# Сценарий видео-демо (60–90 секунд)

Правило одно: **в кадре — настоящий прогон** нашей среды. ИИ допускается как
режиссёр/звукорежиссёр (субтитры, озвучка, нарезка пауз, титры), но не как
«рисовальщик экрана»: подделанный прогон на защите вскроется за один вопрос.

## Подготовка (5 минут)

1. Закрыть лишние вкладки, тема терминала — тёмная, размер шрифта крупный (16–18 pt).
2. Открыть папку проекта в терминале, проверить `python --version`.
3. Начать запись экрана: **Win + Alt + R** (встроенная запись Windows) или OBS.
4. Запустить одну команду:

```bash
python scripts/demo_all.py --pause 2 --srt artifacts/demo.srt
```

`--srt` пишет субтитры **с реальными таймингами прогона** — их можно наложить
в любом редакторе (Clipchamp, CapCut, DaVinci) и озвучить любым TTS.

5. Остановить запись. Весь материал готов: дальше только монтаж.

## Монтаж (что можно делать с помощью ИИ)

- Обрезать паузы и ожидание (реальные цифры в кадре должны остаться нетронутыми).
- Наложить `artifacts/demo.srt` как субтитры; при желании озвучить их TTS.
- Добавить заставку, финальный титр, фоновую музыку **без лицензионных ограничений**.
- Подписывать кадры: «запись реального прогона», «вывод терминала».

## Чего в видео быть не должно

- Сгенерированных «экранов» вместо настоящего вывода.
- Заявлений «наша модель стала лучше» (нет контролируемого сравнения — регламент запрещает).
- Кадров с закрытыми файлами (`closed/truth.json`, seed эпизода, provenance).
- Чужой музыки/видео/шрифтов из интернета без проверки лицензии.

## Резервный вариант (если запись не удалась)

Показать живьём на защите: `python scripts/demo_all.py --fast` (~10 секунд,
те же шесть шагов). Второй вариант — `docker run --rm finrepgym`.
